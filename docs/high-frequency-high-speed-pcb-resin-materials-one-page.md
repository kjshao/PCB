# 高频高速PCB用树脂材料一页式整理（化学视角）

> 说明：下表中的“化学结构”采用**典型单体、重复单元、特征官能团和交联网络**的简化写法，便于工程交流。实际量产板材通常不是单一纯树脂，而是**共混、改性、填料复合**后的层压板体系。供应商列表以**PCB层压板/CCL领域常见厂商**为主，个别柔性或特种树脂补充上游材料厂商。

## 化学视角补充：结构为何决定性能

### 1. 低Dk、低Df通常来自低极性和低极化率

- **PTFE**：全氟碳链的极化率很低，因此Dk、Df都非常低。
- **PPE/PPO**：虽然含有醚键，但整体仍以芳香烃骨架为主，极性低于环氧网络。
- **LCP**：分子链有序、吸水极低，介电性能稳定，适合高频柔性应用。

### 2. 吸水率往往与极性官能团数量相关

- **环氧**固化后会引入较多羟基，羟基越多，吸湿倾向通常越高。
- **PI**含有酰亚胺和羰基结构，耐热虽好，但吸湿通常不如PTFE和LCP。
- **CE、PTFE、LCP**普遍更容易做到低吸水率。

### 3. 耐热性通常来自刚性芳香骨架和高稳定交联结构

- **CE**的三嗪环网络热稳定性高。
- **PI**的芳香族酰亚胺环体系是经典高耐热结构。
- **BT**和其他高交联载板树脂也依赖高刚性、高交联密度来提高热稳定和尺寸稳定。

### 4. 加工性与“是否容易反应、是否容易金属化”密切相关

- **环氧体系**容易固化、黏结和金属化，因此工艺最成熟。
- **PTFE**化学惰性强、表面能低，导致钻孔、表面处理和铜结合更难。
- **碳氢/烃类树脂体系**往往就是为了在高频性能与加工窗口之间取得工程平衡。

## 碳氢树脂路线分析

### 1. 这里说的“碳氢树脂”不是单一树脂名

在高频高速PCB材料里，“碳氢树脂”或“Hydrocarbon Resin”通常不是单一标准聚合物名称，而更像一类**低极性低损耗树脂平台**。工程资料里常见表述包括：

- Hydrocarbon
- Hydrocarbon Ceramic
- Low-loss Thermoset
- PTFE-free low-loss system

其常见化学基础往往包含：

- 芳香族烃类骨架
- 环烯烃或其他低极性烃类结构
- 与PPO/PPE、改性热固组分或填料形成复合体系

### 2. 为什么碳氢树脂容易做成低损耗

碳氢树脂路线之所以重要，核心原因是它通常具备以下结构特点：

- **极性较低**：比传统环氧固化网络更少强极性基团
- **偶极损耗较低**：更容易降低Df
- **吸水倾向较低**：有利于保持介电稳定性
- **可通过填料调节Dk和CTE**：适合构建高频多层板体系

因此它往往处在：

- **性能优于普通环氧**
- **加工性优于纯PTFE**

之间的平衡位置。

### 3. 它和PPO/PPE是什么关系

从工程上看，**碳氢树脂路线和PPO/PPE路线既是并列关系，也常常是重叠关系**。

可以这样理解：

- **PPO/PPE**是一类较明确的芳香醚树脂骨架
- **碳氢树脂**更像一条低极性烃类材料平台路线
- 很多商品化低损耗板材，会把**碳氢树脂 + PPO/PPE + 改性热固组分 + 填料**做成复合体系

所以实际量产中，经常不是“纯碳氢”或“纯PPO/PPE”，而是：

- 碳氢树脂主导，PPO/PPE参与共混
- PPO/PPE主导，碳氢低损耗组分参与调节

### 4. 在高频高速板里的定位

#### 对高频板

碳氢树脂通常对应：

- Hydrocarbon Ceramic
- 高频多层板
- 射频模块板
- 车载雷达板

它是**非PTFE路线中非常重要的高频低损耗方案**。

#### 对高速数字板

碳氢树脂更多体现为：

- 低损耗热固性体系的一部分
- 与PPO/PPE共混的低损耗树脂平台
- 面向多层量产和高速通道的一种工程折中路线

#### 对极限高频/mmWave

如果目标是极限损耗性能，**PTFE通常仍然在上限能力上更强**；碳氢树脂则更多体现为：

- 更好的加工窗口
- 更好的多层适配性
- 更好的综合成本与可靠性平衡

## 选型理解

### 1. 如果重点是高速数字板

优先考虑：

- 改性环氧体系
- PPE/PPO共混体系
- 碳氢/PPO复合低损耗体系
- 低粗糙铜箔和低skew玻纤的整体搭配

这类路线通常在**成本、加工性和高速性能**之间更平衡。

### 2. 如果重点是高频/毫米波

优先考虑：

- PTFE体系
- 碳氢/Hydrocarbon Ceramic体系
- LCP（若为柔性高频互连）

这类路线更看重**Df、Dk稳定性、吸水率和铜面粗糙度**。

### 3. 如果重点是高可靠和高密度

优先考虑：

- CE
- PI
- BT / ABF / MPI

这类路线更关注**耐热性、尺寸稳定性、封装兼容性和长期可靠性**。

## 一句话总结

高频高速PCB树脂材料的演进方向，可以概括为：**从较高极性的传统环氧网络，逐步向低极性、低极化率、低吸水率以及更高交联稳定性的树脂体系扩展**。
