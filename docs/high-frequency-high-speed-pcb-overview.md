# 高频高速PCB材料与技术综述

## 1. 概述

高频高速PCB是同时面向高频射频传输和高速数字互连的印制电路板类型。两类需求在材料和制造工艺上高度重叠：

- **高频PCB**：重点关注微波、毫米波等高频信号的低损耗传输、相位一致性和介电稳定性。
- **高速PCB**：重点关注高速数字信号的阻抗控制、插入损耗、串扰、时延偏差和眼图质量。

从工程实践看，高频高速PCB的核心目标是在**低损耗、阻抗稳定、热机械可靠性和可制造性之间取得平衡**。

## 2. 性能要求

### 2.1 电性能要求

1. **低介电常数（Dk）**
   - 有利于提高信号传播速度，降低时延。
   - 更关键的是Dk在频率、温度和湿度变化下要保持稳定。

2. **低介质损耗（Df）**
   - 决定传输损耗大小。
   - 在高速SerDes链路、射频前端和毫米波应用中尤为关键。

3. **阻抗控制能力强**
   - 要求叠层、介质厚度、铜厚和蚀刻形貌稳定一致。
   - 单端和差分阻抗通常要求更严格的公差控制。

4. **低插入损耗与低回波损耗**
   - 有助于提升长通道传输质量，降低反射和失真。

5. **低串扰与低时延偏差**
   - 对高速差分链路和多通道并行链路非常重要。
   - 需要控制玻纤编织效应带来的skew问题。

### 2.2 热性能要求

1. **较高Tg**
   - 适应回流焊和长期高温工作环境。

2. **较低CTE**
   - 尤其是Z向热膨胀系数要低，以降低过孔和层间失效风险。

3. **较好的导热能力**
   - 面向高功耗芯片、功放和雷达模块等应用。

### 2.3 机械和加工性能要求

1. **尺寸稳定性高**
   - 满足多层对位和细线宽/线距加工要求。

2. **加工性好**
   - 包括钻孔、沉铜、压合和蚀刻等工艺适配能力。
   - PTFE类材料在加工上通常更具挑战。

3. **低粗糙度铜箔适配**
   - 高频下趋肤效应明显，粗糙铜面会增加附加损耗。

### 2.4 可靠性要求

1. **低吸水率**
   - 降低介电性能波动。

2. **抗CAF能力强**
   - 面向多层细间距和长期高可靠应用。

3. **层间结合稳定**
   - 可承受热循环、湿热和振动环境。

## 3. 结构类别

### 3.1 按板型分类

- **刚性板（Rigid PCB）**：通信设备、服务器、工控和雷达设备中最常见。
- **挠性板（FPC）**：用于高频柔性互连、天线和小型模组。
- **刚挠结合板（Rigid-Flex）**：多用于航空航天、军工和高可靠小型化系统。

### 3.2 按层压结构分类

- **单/双面高频板**：用于简单射频链路、天线和模块板。
- **多层高频高速板**：服务器、交换机、基站和车载雷达的主流形式。
- **混压板（Hybrid Stack-up）**：关键层使用高频低损耗材料，其他层使用高速FR-4或常规材料，以兼顾性能和成本。
- **HDI / Any-layer HDI / Build-up结构**：面向高密度互连、封装过渡和高带宽系统。

### 3.3 按传输结构分类

- **微带线（Microstrip）**
- **带状线（Stripline）**
- **共面波导（CPW/CPWG）**

这些结构分别用于外层传输、内层差分互连和射频过渡，常根据损耗、屏蔽和阻抗控制需求进行选择。

## 4. 材料分类

高频高速PCB的关键材料通常包括：

1. 树脂体系
2. 增强材料（玻纤布或其他增强体）
3. 铜箔
4. 填料
5. 半固化片（PP）与覆铜板（CCL）

## 5. 树脂材料类别

### 5.1 改性环氧树脂

- 加工成熟、成本相对友好。
- 适合中高速和部分高端高速应用。
- 常见于低损耗FR-4和高速数字板。

### 5.2 PPO / PPE（聚苯醚/改性聚苯醚）

- 具有较低Dk、较低Df和较低吸水率。
- 在高速通信板和背板中应用广泛。
- 是高速低损耗材料的重要路线之一。

### 5.3 PTFE（聚四氟乙烯）

- 具有极低损耗和优异的高频稳定性。
- 常用于微波、毫米波、雷达和卫星通信板。
- 缺点是加工难度大、成本高、混压复杂。

### 5.4 烃类/陶瓷填充树脂

- 高频性能好，加工性优于纯PTFE。
- 是高频性能与批量制造能力之间的折中方案。

### 5.5 氰酸酯树脂（CE）

- 低损耗、低吸水、热稳定性好。
- 适合高可靠高频高速场景。

### 5.6 BT树脂

- 具有较好的耐热性和尺寸稳定性。
- 更多见于IC载板和封装基板方向。

### 5.7 聚酰亚胺（PI）

- 耐热性能突出，适合FPC和高温环境。
- 但吸水率和高频损耗并不总是最优。

### 5.8 LCP（液晶聚合物）

- 吸水率极低，适合高频柔性场景。
- 常用于高频FPC、毫米波天线和模组。

### 5.9 ABF / MPI等载板树脂

- 适用于高密度build-up和先进封装互连。
- 常见于AI/HPC和高端IC载板。

## 6. 玻纤布材料类别

### 6.1 E-glass

- 最常用、最成熟的电气级玻璃纤维。
- 成本低，但在更高频高速应用中需要优化编织效应。

### 6.2 低Dk玻纤布

- 用于降低整体介电常数。
- 有利于改善损耗和信号一致性。

### 6.3 NE-glass

- 相比普通E-glass具有更低Dk。
- 常用于高端高速和高频材料体系。

### 6.4 S-glass

- 机械性能较高。
- 更多体现机械优势，而非纯粹的高频电性能优势。

### 6.5 Quartz Cloth（石英纤维布）

- 介电性能优异，适合超高频和高可靠场景。
- 成本较高，加工门槛也更高。

### 6.6 Spread Glass

- 通过更均匀的纱束分布降低玻纤编织效应。
- 对高速差分通道的低skew设计非常有帮助。

## 7. 其他关键材料

### 7.1 铜箔类别

- **ED铜箔**：通用性强，但高频损耗相对更高。
- **RTF铜箔**：兼顾结合力与较平滑表面。
- **VLP / HVLP铜箔**：表面粗糙度更低，更适合高频高速板。
- **RA铜箔**：常用于特殊高频和柔性应用。

### 7.2 填料类别

- 陶瓷填料
- 二氧化硅
- 低介电填料

主要用于调节Dk、CTE、导热能力和尺寸稳定性。

## 10. 常见高频高速板材厂商体系

### 10.1 Rogers

- 主要路线：PTFE、陶瓷填充PTFE、Hydrocarbon Ceramic
- 典型应用：基站、雷达、卫星通信、毫米波天线
- 行业定位：高频射频材料的代表性厂商

### 10.2 Panasonic

- 主要路线：低损耗高速树脂体系
- 典型应用：服务器、交换机、背板、高速通信板
- 行业定位：高速数字板材料的重要代表

### 10.3 Isola

- 主要路线：低损耗环氧、PPE/PPO、高速树脂体系
- 典型应用：通信设备、高速互连板、背板
- 行业定位：高端高速PCB领域常见国际方案

### 10.4 EMC（台光）

- 主要路线：高速FR-4和低损耗材料体系
- 典型应用：服务器、交换机、数据中心板卡
- 行业定位：量产型高速板材料的重要供应商

### 10.5 ITEQ（联茂）

- 主要路线：改性环氧和低损耗高速板材
- 典型应用：通信板、网络设备、服务器板
- 行业定位：高速数字板量产常见材料体系

## 11. 发展趋势

1. **向更低损耗等级演进**
   - 从普通FR-4向Mid-loss、Low-loss、Very-low-loss、Ultra-low-loss升级。

2. **向更高频段发展**
   - 从GHz级持续扩展到毫米波、车载77/79GHz和6G预研频段。

3. **向更高带宽发展**
   - 从25G/56G向112G/224G PAM4升级，对材料和铜箔要求更高。

4. **低粗糙度铜箔成为关键方向**
   - VLP、HVLP及更优表面处理方案应用持续增加。

5. **低skew玻纤材料需求提升**
   - Spread Glass和低编织效应玻纤布将更广泛应用于高速差分链路。

6. **混压结构更加普遍**
   - 关键层使用高端材料，非关键层使用成本更优材料，形成性能与成本平衡。

7. **与先进封装融合加深**
   - PCB、载板、Chiplet和光电共封装之间的边界持续模糊。

## 12. 一页式总结

| 维度 | 结论 |
| --- | --- |
| 核心目标 | 实现低损耗、阻抗稳定、低时延偏差和高可靠性 |
| 关键材料 | 低损耗树脂、低Dk玻纤、低粗糙铜箔、功能性填料 |
| 主流路线 | 高速FR-4升级、PPE/PPO、PTFE、烃类陶瓷填充、LCP/PI、ABF/BT |
| 关键趋势 | 更低损耗、更高频率、更高带宽、更多混压、更多低skew材料 |
| 典型应用 | 服务器、交换机、基站、雷达、卫星通信、毫米波模组、IC载板 |
