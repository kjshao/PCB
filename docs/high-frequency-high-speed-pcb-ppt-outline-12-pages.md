# 高频高速PCB专题汇报PPT提纲（12页版）

## 使用说明

本提纲基于前面已经整理的高频高速PCB资料，按“**应用热点 -> 性能需求 -> 产业链与头部厂商 -> 材料分解 -> 树脂演进 -> 研发机会点**”的逻辑展开，适合作为一份 **10-15页技术/产业结合型汇报PPT** 的骨架。

建议风格：

- 面向管理层：结论先行、图表化、减少过深机理
- 面向研发/材料团队：保留材料路线、参数和机会点
- 推荐页数：**12页**

## 第2页：最近热门的高频高速应用有哪些

### 建议标题
**高频高速PCB的主要需求来源**

### 核心结论
当前高频高速PCB需求主要由 **AI服务器/交换机、车载雷达、卫星通信、5G/6G、光模块与高速互连** 驱动。

### 主要内容
- AI服务器、交换机、背板：112G/224G高速数字通道
- 车载雷达：77/79GHz毫米波
- 卫星互联网/相控阵：高频、高可靠、低损耗
- 5G/6G与射频前端：基站、天线、滤波器、馈线
- 高速光模块：短距高带宽互连

## 第3页：这些应用对PCB板提出了什么性能要求

### 建议标题
**应用升级如何传导到PCB性能要求**

### 核心结论
不同应用最终都在推动PCB向 **低损耗、低skew、低CTE、高可靠、可量产** 升级。

### 主要内容
- 高速数字板：低插损、低串扰、低skew、阻抗稳定
- 高频/毫米波板：低Df、稳定Dk、低吸水、相位一致性
- 高功率模块：导热、热稳定、长期可靠性
- 多层高密度板：尺寸稳定、压合窗口、CAF可靠性

## 第4页：高频高速PCB的核心性能指标

### 建议标题
**高频高速PCB的关键评价指标**

### 核心结论
高频高速PCB不是只看Dk/Df，而是电、热、机械、制造四类指标共同决定。

### 主要内容
- 电性能：Dk、Df、插入损耗、回波损耗、阻抗控制
- 热性能：Tg、Td、CTE、导热性
- 机械可靠性：尺寸稳定、层间结合、钻孔质量
- 制造性：多层压合、混压、细线路、量产一致性

## 第5页：Top PCB板生产商与能力分层

### 建议标题
**高频高速PCB制造能力主要集中在哪些头部板厂**

### 核心结论
高频高速PCB的竞争，不只是材料竞争，更是**板厂工艺能力 + 材料体系导入能力**的竞争。

### 主要内容
- 国际/全球高端制造能力代表：
  - TTM
  - AT&S
  - Unimicron
  - Compeq
  - Tripod
- 国内高端PCB能力代表：
  - 深南电路
  - 沪士电子
  - 胜宏科技
  - 鹏鼎控股（部分高端板卡/互连场景）
- 核心能力差异：
  - 高频材料混压能力
  - 低损耗材料验证能力
  - 多层/高层板加工能力
  - 高速阻抗与一致性控制

### 建议图表
- “板厂能力金字塔”：普通多层 -> 高速多层 -> 高频混压 -> 毫米波/高可靠

> 说明：这里的“Top”侧重高频高速板制造能力认知，不等同于单一维度的全球营收排名。

## 第6页：Top板材/材料厂商与代表板材

### 建议标题
**高频高速板材平台主要由哪些厂商主导**

### 核心结论
高端高频高速板材路线，主要由 **Rogers、Panasonic、Isola、Taconic、EMC、ITEQ** 等材料平台主导。

### 主要内容
- Rogers：RT/duroid、RO3000、RO4000、RO4835T
- Panasonic：Megtron 系列
- Isola：Astra MT77、Tachyon 100G
- Taconic：高端PTFE与非PTFE高频路线
- EMC（台光）、ITEQ（联茂）：高速低损耗量产路线
- 可按路线分组：
  - PTFE路线
  - Hydrocarbon Ceramic路线
  - PPO/PPE/低损耗热固路线

## 第7页：一块高频高速PCB，材料到底由哪些部分构成

### 建议标题
**高频高速PCB材料拆解：不只是树脂**

### 核心结论
高频高速PCB的最终性能，由 **树脂、铜箔、玻纤布、填料** 四大类材料协同决定。

### 主要内容
- 树脂：决定Dk、Df、吸水率、加工性
- 铜箔：决定表面损耗、粗糙度相关损耗、细线路能力
- Low-Dk玻纤布/石英布：决定Dk、Df、skew、尺寸稳定性
- 填料：决定CTE、尺寸稳定、导热、部分Dk/Df

## 第8页：树脂路线对比——PTFE、碳氢、PPO/PPE

### 建议标题
**三条核心树脂路线：PTFE vs 碳氢 vs PPO/PPE**

### 核心结论
- PTFE 代表**高频性能上限**
- 碳氢路线代表**高频性能与工艺平衡**
- PPO/PPE 代表**高速数字低损耗量产主线**

### 主要内容
- PTFE：Df最低，但加工难、成本高
- 碳氢路线：非PTFE高频主力，适合多层和混压
- PPO/PPE：适合112G/224G、高层大板量产

## 第9页：关键辅助材料路线——铜箔、玻纤布、填料

### 建议标题
**决定“最后一公里性能”的关键辅助材料**

### 核心结论
很多时候，不是树脂本身拉不开差距，而是 **铜箔粗糙度、玻纤编织效应、填料体系** 决定最后的性能高低。

### 主要内容
- 铜箔：ED -> LP -> VLP -> HVLP -> UHVLP
- Low-Dk玻纤布：改性E-glass -> Low-Dk -> NE-glass -> Spread Glass
- 石英布：极高端增强路线
- 填料：球形硅微粉、高纯石英、低损耗陶瓷、BN导热填料

## 第10页：树脂演进方向是什么

### 建议标题
**树脂体系的演进逻辑：从单一材料到复合平台**

### 核心结论
未来树脂演进不是某一种材料替代全部，而是 **PTFE高端化、碳氢平台化、PPO/PPE高速化、体系复合化**。

### 主要内容
- PTFE：改性PTFE、陶瓷填充PTFE、低CTE、多层化
- 碳氢路线：Hydrocarbon Ceramic、非PTFE高频多层化
- PPO/PPE：与环氧、CE共混，持续降低Df和吸水率
- 共同方向：
  - 更低Df
  - 更低吸水
  - 更低CTE
  - 更适合量产

## 第11页：高分子材料研发可能的机会点在哪里

### 建议标题
**高分子材料研发的潜在机会点**

### 核心结论
高频高速材料研发机会，不在“单点追求最低Df”本身，而在**低损耗 + 可加工 + 低CTE + 量产一致性**的综合突破。

### 主要内容
- 机会点1：更低极性的非PTFE低损耗树脂平台
- 机会点2：PPO/PPE 与环氧/CE/碳氢体系共混优化
- 机会点3：低吸湿、低skew、低CTE的系统匹配
- 机会点4：适合多层板和混压板的高频树脂体系
- 机会点5：面向高功率高频模块的导热低损耗体系
- 机会点6：面向国产替代的整套材料平台开发

## 第12页：总结与建议

### 建议标题
**总结：高频高速PCB材料的竞争，本质是系统材料平台竞争**

### 核心结论
- 热门应用正推动PCB向更高频、更高速、更低损耗发展
- 板厂能力与材料平台能力正在深度耦合
- 树脂、铜箔、玻纤布、填料必须协同设计
- 高分子研发机会主要集中在“低损耗 + 可制造 + 高可靠”的综合平衡

### 可落地建议
- 如果做产业研究：重点跟踪应用 -> 材料路线 -> 头部供应链
- 如果做材料研发：重点布局PPO/PPE共混、非PTFE低损耗平台、低CTE与低吸湿体系
- 如果做国产替代：优先从Low-Dk玻纤布、硅基填料、高速低损耗树脂平台切入
